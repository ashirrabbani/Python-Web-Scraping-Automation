# E-Commerce Web Scraper & Data Extractor

A Python-based automated web scraping script designed to extract product listings, real-time pricing, and stock availability from e-commerce platforms and export them into structured CSV files.

## Features
* **Automated Data Extraction:** Scrapes book titles, prices, and stock statuses.
* **Structured Output:** Cleans raw HTML text and formats values into a ready-to-use CSV file.
* **Error Handling:** Validates HTTP response codes before parsing content.

## Tech Stack
* **Language:** Python 3.x
* **Libraries:** `requests`, `beautifulsoup4`, `csv`
